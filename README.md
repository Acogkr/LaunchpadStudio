# Launchpad Studio

macOS의 기존 Launchpad를 정리하는 앱입니다.

[한국어](docs/README.ko.md) · [English](docs/README.en.md) · [日本語](docs/README.ja.md) · [简体中文](docs/README.zh-Hans.md)

## 주요 기능

- 앱 자동 분류와 사용자 지정 규칙
- 앱 이동, 폴더 이름 변경과 적용 전 미리보기
- 적용 전 자동 백업과 이전 배치 복원
- 자동 저장, 실행 취소·다시 실행
- 새 앱 감지 알림과 Launchpad 자동 동기화
- 앱·관련 파일 삭제와 복원, 중요한 앱 삭제 보호
- 남은 파일 정리와 휴지통 비우기
- GitHub 새 버전 확인과 상단 업데이트 버튼
