# Launchpad Studio

macOS標準のLaunchpadを整理するアプリです。

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## 主な機能

- アプリの自動分類とカスタムルール
- アプリの移動、フォルダ名の変更、適用前のプレビュー
- 適用前の自動バックアップと以前の配置の復元
- 自動保存、取り消し、やり直し
- 新しいアプリの通知とLaunchpadの自動同期
- アプリと関連ファイルの削除・復元、大切なアプリの削除保護
- 残存ファイルの整理とゴミ箱を空にする機能
- GitHubでの新バージョン確認と上部のアップデートボタン
