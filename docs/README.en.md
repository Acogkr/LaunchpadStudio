# Launchpad Studio

A macOS app for organizing your existing Launchpad.

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## Features

- Automatic app grouping and custom sorting rules
- Move apps, rename folders, and preview changes
- Automatic backups before applying changes and layout restoration
- Autosave, undo, and redo
- New app notifications and automatic Launchpad synchronization
- Remove apps and related files, restore deletions, and protect important apps
- Find leftover files and empty Trash
- Check GitHub for new versions with a persistent update button
