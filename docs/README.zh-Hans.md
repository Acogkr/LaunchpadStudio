# Launchpad Studio

一款整理 macOS 原有启动台（Launchpad）的应用。

[한국어](README.ko.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

## 主要功能

- 应用自动分类与自定义规则
- 移动应用、修改文件夹名称，并在应用更改前预览布局
- 应用更改前自动备份，并可恢复以前的布局
- 自动保存、撤销和重做
- 新应用提醒与启动台自动同步
- 删除和恢复应用及相关文件，保护重要应用不被删除
- 查找残留文件与清空废纸篓
- 检查 GitHub 新版本并显示顶部更新按钮
